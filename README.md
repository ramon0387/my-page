# Ideal & real buffers
These scripts allow to calculate amounts (g) either the acid as the conjugated base in order to prepare buffer sistems under standar conditions and when the ionic strength is cero as well. Everyone can invocate either ideal_buffer.py as real_buffer files program from Linux or Mac OS command lines throught Python language, when program is invocated sudenly the entry options for variables will appeare -- they can be integers or floats; then, the program will iniciate the calculus. Once it will finish to make the operations the result will be printed on screen.
